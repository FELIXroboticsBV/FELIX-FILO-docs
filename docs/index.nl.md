# FELIX FILO

!!! tip "Bedankt"

    Bedankt dat u voor FELIX Printers heeft gekozen als leverancier van uw 3D-printer.

Welkom bij de documentatie van de FELIX FILO! Deze website is uw gids voor het gebruik van onze applicatie!

## Achtergrond

De FELIX-FILO wordt aangedreven door de Cura-slicer, dus als u bekend bent met het gebruik hiervan, zou het gebruik van deze applicatie erg eenvoudig moeten zijn.
