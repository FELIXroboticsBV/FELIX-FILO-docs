# Getting started

This page will provide you with information on how to complete the welcome wizard of the FELIX-FILO

## Completing welcome wizard

When you first open the application you are going to be met with the initial configuration pop-up that looks like this

<figure markdown="span">
  ![Welcome pages](../Images/getting-started/welcome-page.png){ width="300" }
  
<figcaption>First welcome page of the application</figcaption>
</figure>

!!! note

    This welcome window is only available in English because the the langue is not yet configured. IF you would like to visit Welcome dialog in other langues
    please change the language in this documentation

After you pressed `Get started` you will be redirected to accept user agreements. Press `Agree` to continue.

!!! warning

    If you do not agree with our user agreements please contact us.

<figure markdown="span">
  ![Welcome pages](../Images/getting-started/user-agreement.png){ width="300" }
  
<figcaption>Accept user agreement of the application</figcaption>
</figure>

As a next step you are required to select a printer you own and for which you would like to configure the program.

Select `Add FELIX Printer`.

<figure markdown="span">
  ![Welcome pages](../Images/getting-started/get-printer.png){ width="300" }
  
<figcaption>Select FELIX Printer</figcaption>
</figure>

If you have done everything correctly you should see window prompting you to select either printer over the network or non-network printer.

<figure markdown="span">
  ![Welcome pages](../Images/getting-started/network-vs-non-network.png){ width="400" }
  
<figcaption>Overview of configuring various printers</figcaption>
</figure>

You are going to be interacting with the list `Add a non-networked printer`. In order to do that click on it. This should show you the list with various printers to choose from.

Depending on the printer you are using select it from the list and optionaly give it a name.

!!! Note

    For troubleshooting purposes we advise you to keep the name as it is.

Once the printer is selected press `Next` after which you are going to be presented with a list of options. We advise you to not change anything and continue with again pressing `Next`.

After this you should be presented into the main view of the application

<figure markdown="span">
  ![Welcome pages](../Images/getting-started/main-view.png){ width="800" }
  
<figcaption>Main viewport of the application</figcaption>
</figure>
